PROPERTY RUSH MOBILE ONLINE

Telefon için optimize edilmiş online multiplayer sürüm.

ÖZELLİKLER
- 2-4 oyuncu
- Oda kodu ile katılım
- Telefon / tablet / bilgisayar tarayıcısından oynama
- Mobilde büyük butonlar ve sabit tur kontrolleri
- Oda kodunu tek dokunuşla kopyalama
- Her oyuncunun eli gizli
- Socket.IO ile gerçek zamanlı bağlantı
- Render deploy yapılandırması hazır

YERELDE ÇALIŞTIRMA
1. Node.js kurulu olmalı.
2. Proje klasöründe:
   npm install
   npm start
3. Bilgisayarda:
   http://localhost:3000

AYNI WI-FI ÜZERİNDEN TELEFONDAN
Bilgisayarın yerel IP adresini öğren.
Örnek:
   http://192.168.1.25:3000
Telefon ve bilgisayar aynı Wi-Fi ağına bağlı olmalı.

RENDER İLE İNTERNETE YAYINLAMA
1. GitHub'da yeni bir repository oluştur.
2. Bu klasördeki dosyaları repository'ye yükle.
3. Render.com hesabına giriş yap.
4. New + > Blueprint seç.
5. GitHub repository'yi bağla.
6. render.yaml otomatik algılanır.
7. Deploy tamamlandığında Render sana bir HTTPS adresi verir.
8. Bu adresi arkadaşlarına gönder.
9. Bir kişi oda oluşturur, diğerleri oda koduyla katılır.

ÖNEMLİ
Ücretsiz hosting servisleri kullanılmadığında uykuya geçebilir. İlk açılış birkaç saniye sürebilir.
